# 启明 QIMING · PureInsight 官网

香港聃清信息咨询有限公司（品牌：启明 QIMING / PureInsight）官方网站。

## 技术栈

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- 字体：Noto Serif SC / Noto Sans SC

## 本地开发

```bash
npm install
npm run ingest   # 从 ../读博 与 ../金融分析 抽取并分类文章
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## 阅读专栏

- 自动分类：金融学 / 经济学 / 心理学 / 科学技术 / 教育 / 哲学人文 / 社会议题
- 免费预览首页，演示支付 USD 9.99 解锁全文（Cookie）
- 界面语言：简体中文 / 繁體中文 / English（正文简繁自动转换）
