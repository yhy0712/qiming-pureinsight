# 启明 QIMING · PureInsight 官网

香港聃清信息咨询有限公司（品牌：启明 QIMING / PureInsight）官方网站。

## 技术栈

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- 字体：Noto Serif SC / Noto Sans SC

## 本地开发

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。
